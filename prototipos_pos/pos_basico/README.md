# POS Básico — Prototipo demostrativo

## Cómo ejecutar
Opción rápida: abre `index.html` con doble clic. Para probar instalación PWA usa un servidor local:

```bash
python -m http.server 8080
```

Luego abre `http://localhost:8080`.

## Incluye
Dashboard, punto de venta touch, productos, categorías, inventario, caja, tickets, historial, reportes básicos, usuarios y configuración. Los datos se guardan en `localStorage`.

## Credenciales demo
No se requiere inicio de sesión. Usuarios precargados: Administrador (PIN 1234) y Caja 1 (PIN 1111).

## Restablecer
Usa el botón **Restablecer demo** para volver a los datos iniciales.
