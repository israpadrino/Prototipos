# Web Informativa — Prototipo demostrativo

Abre `index.html` directamente. Para probar la instalación PWA ejecuta `python -m http.server 8080` y abre `http://localhost:8080`.

Incluye inicio, nosotros, productos/servicios, catálogo, galería, horarios, ubicación, contacto, botón de WhatsApp simulado y experiencia responsive. Los datos son ficticios de una pastelería.

No requiere credenciales ni backend.
