# POS Estándar — Prototipo demostrativo

Ejecuta `index.html` directamente o usa `python -m http.server 8080` para probarlo como PWA.

Incluye todo el flujo comercial del POS Básico y agrega inventario avanzado, entradas/salidas, proveedores, clientes frecuentes, gastos, apertura/cierre de caja, usuarios, roles, permisos, reportes avanzados, administración adaptable a celular, estaciones simuladas e historial de movimientos.

Los datos se guardan en `localStorage`. No requiere credenciales para la demo. Usa **Restablecer** para recuperar los datos ficticios originales.
