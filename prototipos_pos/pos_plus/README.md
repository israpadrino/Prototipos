# POS Plus — Prototipo demostrativo

Abre `index.html` o ejecuta `python -m http.server 8080` en esta carpeta para probar instalación PWA.

Incluye las funciones comerciales de los planes anteriores y agrega múltiples cajas y terminales, crédito/fiado, clientes con saldo, abonos, historial de crédito, roles avanzados, autorizaciones, automatizaciones simuladas, dashboard del dueño optimizado para móvil, notificaciones y auditoría.

No requiere credenciales. La información se conserva con `localStorage`; **Restablecer** devuelve la demo a su estado inicial.

## Gestión de catálogo
Las altas de productos nuevos quedan reservadas para soporte. Esto evita cambios accidentales en el catálogo y mantiene controlada la configuración comercial.
